# Chinese Addons（中文扩展）

一个专门提供中文内容源的扩展集合。

# 📦 关于项目

Chinese Addons 是一个用于收集和分享中文内容扩展的开源项目，旨在为用户提供更多中文影视及其他内容来源。

# ✨ 项目特点

- 提供中文内容源。
- 支持多种内容扩展。
- 持续更新和改进。
- 简单便捷的安装方式。

# 📥 安装说明

下载所需的扩展文件，并按照应用程序提供的安装说明进行安装。
